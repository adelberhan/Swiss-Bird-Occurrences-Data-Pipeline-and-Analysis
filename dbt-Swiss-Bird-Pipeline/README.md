# dbt Swiss Bird Pipeline

## Overview

This directory houses the dbt transformation layer for the Swiss Bird Occurrences data platform.

The active dbt project is located in:

- **[`dbt_project/`](./dbt_project/)**: The full dbt project implementing Snowflake modeling across `RAW_DATA`, `CURATED`, and `SERVING` schemas.

Please refer to the comprehensive [**dbt Project Documentation (`dbt_project/README.md`)**](./dbt_project/README.md) for data lineage, model specifications, schema tests, macros, and CLI commands.
